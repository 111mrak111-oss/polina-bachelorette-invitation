# Приглашение на девичник Полины

Анимированный одностраничный сайт на чистых HTML, CSS и JavaScript. Сборка и серверная часть не нужны; проект готов к публикации через GitHub Pages.

## Как изменить дату, время, адрес и тексты

Откройте `script.js`. В самом начале файла находится объект `invitationConfig` — все персональные тексты сайта собраны в нём. Замените значения в кавычках, например:

```js
date: "18 июля 2027",
time: "17:00",
place: "Название места, улица и дом",
```

Не удаляйте запятые между строками. Изображения лежат в `images/cats/` и подключены относительными путями, поэтому корректно работают в подпапке GitHub Pages.

## Как открыть локально

Самый простой способ — дважды нажать `index.html`. Для проверки в условиях, близких к GitHub Pages, запустите из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере. Для загрузки шрифтов и библиотек GSAP потребуется интернет.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в ветку `main` всё содержимое этой папки, включая `index.html` и `images/`.
2. Откройте в репозитории **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через несколько минут GitHub покажет ссылку на опубликованный сайт.

## Доступность и анимация

- Конверт открывается нажатием, касанием, клавишей Enter или пробелом.
- При включённой системной настройке `prefers-reduced-motion` движение отключается, а содержимое доступно сразу.
- Звук на сайте не используется и автоматически не запускается.
- Основной дизайн рассчитан прежде всего на телефоны шириной 320–430 px.

## Об изображениях

Коллаж котиков **сгенерирован по мотивам фотографий**. PNG не являются точными вырезками исходных снимков. Все 11 файлов имеют прозрачный фон; их пропорции сохраняются, изображения не растягиваются.
